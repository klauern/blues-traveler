## Known Issues & Bug Reports

### GitHub Issues

| Issue | URL | Topic | Status |
|-------|-----|-------|--------|
| #5489 | https://github.com/anthropics/claude-code/issues/5489 | Environment variable substitution | Open |
| #9567 | https://github.com/anthropics/claude-code/issues/9567 | Hook environment vars empty | Open |

### Common Problems

1. **Environment Variable Substitution**
   - `CLAUDE_TOOL_NAME` and `CLAUDE_TOOL_PARAMS` sometimes fail
   - Variables appear as literal strings
   - Workaround: Use JSON stdin

2. **JSON Parsing Interference**
   - Shell profile output breaks JSON parsing
   - Hooks fail silently
   - Solution: Redirect to stderr

3. **Stop Hook Infinite Loops**
   - Not checking `stop_hook_active`
   - Claude never stops
   - Solution: Check field value
